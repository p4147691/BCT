# BCT

BCT는 사용자가 지시한 개발 작업을 단순한 구조로 끝까지 수행하기 위한 새 제어 프로젝트다.

## 현재 상태

PROJECT_INITIALIZED / DESIGN_PROPOSED. 설계와 이전 계획을 기록한 단계이며 실행 코드, ACT 대체, LIVE 전환은 아직 구현하지 않았다. 현재 ACT는 계속 운영한다.

## 목표

- 기존 ACT의 검증된 파일·Git·테스트·배포·서비스·RCC 기능을 가능한 한 재사용한다.
- 사용자 설정은 한곳에서 관리한다.
- 노드 이름, 역할, 그룹, 브라우저 연결을 독립적으로 변경할 수 있게 한다.
- 사용자 요청 범위의 정상 작업은 이어서 처리하고, 실제 충돌·권한 확대·중복 실행 위험은 명확한 이유와 함께 처리한다.
- 작업 시작부터 결과 확인까지 같은 작업 ID로 추적한다.
- 기존 기능 전체를 이전 목표로 삼되 기능별 검증 전에는 호환 완료로 표시하지 않는다.

## 제안 구조

`사용자/MCP → BCT core → adapter → 기존 실행 기능`

Core는 작업과 공통 정책 판단을 관리한다. Adapter는 기존 기능의 입력·출력 계약을 연결한다. 실행기는 실행 직전 대상 상태를 검증하고 결과를 기록한다.

구현 초기에는 하나의 프로세스와 하나의 패키지를 기본으로 한다. 별도 정책 서버나 메시지 브로커를 선행 도입하지 않는다.
